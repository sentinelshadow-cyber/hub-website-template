# Shadow Hub

A modern, customizable hub website template built with HTML, CSS and JavaScript.

## ✨ Features

* Modern hub-style design
* About / personal section
* Product & project showcase
* Multiple pages and links
* Responsive design
* Example data included for showcase

## 📁 File Structure

```text
shadow-hub/
├── assets/              # Website assets
├── shadowcloud/         # Shadow Cloud files
├── shadowcloud-site/    # Shadow Cloud website
├── website-preview/     # Preview screenshots
├── ecosystem.html       # Ecosystem page
├── index.html           # Main homepage
├── shadow-studios.html  # Shadow Studios page
├── shadow-supply.html   # Shadow Supply page
├── sc-server.js         # Local server
└── style.css            # Main stylesheet
```

## ⚠️ Before Using

The included Shadow data is **demo/showcase data** to demonstrate how the template looks.

Replace the names, images, products, links, social accounts, and other Shadow-specific information with your own.

## 🚀 Run Locally

```bash
node sc-server.js
```

Then open the local URL shown in your terminal.
